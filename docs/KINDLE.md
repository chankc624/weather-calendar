# Kindle 雲端圖片

延續既有 CHAN Family Dashboard 雲端方案：GitHub Actions 每小時第 17 分鐘執行 `generate_kindle.py`，產生 `kindle/dashboard.png`。排程可能延遲，不保證準點。

圖片為 1448×1072 橫向、8-bit 灰階 PNG，保留日期、澳門天氣、月曆和既有家庭資料；不顯示時鐘、時間戳或澳門氣象警告，亦不讀取 SMG 警告服務。根目錄及 v2 的瀏覽器頁面維持各自行為。

此功能只產圖，不會安裝或改動 Kindle。畫面方向、拉圖、快取、喚醒及顯示方式仍須在確認實機型號與固件後獨立適配；產圖成功不代表設備部署完成。不要執行 PW3／5.12.3 教程中的安裝包來處理 PW4／5.18.1。

## 電腦預覽

需要 Python 3.9+、Pillow 和中文字型。Ubuntu 使用 `fonts-noto-cjk`；macOS 可設定 `KINDLE_FONT` 與 `KINDLE_FONT_BOLD` 指向已安裝的中文字型。缺字型會停止，不產生方框文字。

```sh
python generate_kindle.py
```

天氣需連線 Open-Meteo；請求失敗、資料格式無效或時間相差超過三小時，會明確顯示資料暫不可用。產生圖片不代表已取得即時天氣。圖片先寫暫存檔再替換，避免留下半張圖片。

公開倉庫的圖片與原始碼均可被他人讀取。此版本沿用歷史版本已有的家庭設定，請勿再加入私人行程或密鑰。

## Kindle 部署前

先保存 USB 可見資料並逐檔核對 SHA-256。這不是完整系統備份。越獄、hotfix、OTA 和設備端部署各自需要使用者逐階段批准。不得把檔案放進 Kindle 根目錄後重啟來試驗相容性。
